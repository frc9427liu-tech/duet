常見問題

Duet 是什麼?

一套讓手機和電腦連動的工具:電腦端是 Windows 程式,手機端是 App。電腦上也加了一些桌面小工具,但核心是兩邊互通。

我的檔案會經過你們的伺服器嗎?

不會經過我們:我們沒有伺服器也沒有帳號系統。連線走你自己電腦建立的 Cloudflare 臨時通道,流量會經過 Cloudflare 的網路。

連線網址安全嗎?

網址含隨機密碼,請勿外傳;關閉分享或重開電腦就失效。目前是公開測試,固定網址與更嚴格驗證在規劃中。

目前不支援什麼?

桌面端只有 Windows;Android 版沒有日曆與剪貼簿;連線網址每次重開會變;安裝程式尚未簽章,Windows 可能出現 SmartScreen 提示。

Mac 或 Linux 能用嗎?

目前桌面端只支援 Windows,Mac 版尚未開發。

誰做的?

FRC 9427 程式組成員的學生專題,仍在持續改進,歡迎回報問題與建議。

iPhone 安裝教學(從零開始,第一次約 20~30 分鐘;之後免費、不用付費開發者帳號)

先確認:iPhone 有設鎖屏密碼、系統 iOS 15 以上;一台 64 位元 Windows 電腦(Windows 10 on ARM、32 位元不支援);一條傳輸線;一組 Apple ID(免費,建議另開一個專用的);安裝時手機要連 WiFi(行動網路不行)。

為什麼這麼麻煩?Apple 不讓 iPhone 直接裝 App Store 以外的 App。SideStore 是用你自己的免費 Apple ID 幫 App 簽章的工具,只有「第一次」要用電腦裝,之後都在手機上完成。

A. 手機先準備(2 分鐘)
1) 在 App Store 搜尋並安裝「LocalDevVPN」。
2) 打開 LocalDevVPN,點「Connect」,出現「允許加入 VPN 設定」時按「允許」並輸入手機密碼。(之後每次要安裝或續簽 App 時,都要先打開它並連線。)

B. 電腦準備(5~10 分鐘)
1) 安裝 iTunes(從 Microsoft Store 或 Apple 官網下載;沒有它電腦認不到 iPhone)。
2) 下載並安裝 iloader:iloader 安裝檔(.msi)。

C. 把 SideStore 裝到手機(5 分鐘)
1) 用傳輸線接上電腦和 iPhone,手機跳出「信任這台電腦?」按「信任」並輸入密碼。
2) 打開 iloader → 用 Apple ID 登入(注意大小寫)→ 選你的 iPhone → 點「Install SideStore (Stable)」。
3) 等它跑完,手機桌面會出現 SideStore。

D. 在手機上信任並啟動 SideStore(3 分鐘)
1) 手機「設定 → 一般 → VPN 與裝置管理」→ 在「開發者 App」下點你的 Apple ID → 「信任」。
2) iOS 16 以上:到「設定 → 隱私權與安全性」最下面打開「開發者模式」,手機會重新開機,開機後再按「開啟」。
3) 打開 LocalDevVPN → Connect。
4) 打開 SideStore,用同一組 Apple ID 登入。
5) 點下方「My Apps」,點 SideStore 右邊寫著「7 DAYS」的按鈕,讓它自己續簽一次完成設定;跳出「撤銷或建立新憑證」時按「Yes / Refresh Now」。

E. 裝 Duet(2 分鐘)
1) 用 iPhone 開這個網頁,按上面的「用 SideStore 開啟」(或按「複製來源網址」,到 SideStore → Sources → + 貼上)。
2) 在來源裡點 DuetLink → 取得(GET)。
3) 裝好後打開 Duet,會有 5 頁新手導覽。

F. 之後怎麼維持
免費 Apple ID 的 App 每 7 天會過期。每隔幾天:打開 LocalDevVPN 連線 → 打開 SideStore → 「My Apps」點「Refresh All」。SideStore 也會在背景幫你續簽,但需要 LocalDevVPN 開著、且手機在 WiFi。過期的 App 打不開,續簽後就恢復,資料不會掉。

常見問題
• 電腦認不到 iPhone:確認 iTunes 裝好、換一條線或 USB 孔、手機要解鎖並按過「信任」。
• SideStore 說找不到配對檔 / 無法連線:先打開 LocalDevVPN 連線再試;手機更新或重設系統後配對檔會失效,要用 iloader 重新裝一次。
• 第 D 步找不到「開發者模式」:先完成 C 步(裝好 SideStore)之後這個選項才會出現。
• 同時最多 3 個側載 App(免費帳號的限制)。
• 我們的 App 沒上架 App Store,是因為 Apple 要每年 US$99 的開發者帳號,目前選擇不付;付了就能改成「點連結就裝」。

更完整、會隨 iOS 版本更新的官方說明:docs.sidestore.io(英文)。畫面文字可能因 iOS 版本略有不同。
